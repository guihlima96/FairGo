# FAIRGO Compliance

## REG-001.0 — São José dos Campos, SP

Consulta normativa em 28/11/2026. Base técnica `9e6229c45b83b2ecf15fe7d62e04ed0d0e6f0a2f`, após a [PR #26](https://github.com/guihlima96/FairGo/pull/26). O FAIRGO está em desenvolvimento e homologação interna, ainda sem CNPJ. O enquadramento como PRC considera a futura intermediação de transporte individual privado remunerado de passageiros. A operação comercial depende da regularização empresarial, fiscal e municipal e dos controles operacionais aplicáveis.
